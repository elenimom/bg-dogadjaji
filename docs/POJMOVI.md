# Pojmovi kroz projekat

## Prva celina
- Node.js izvršava JavaScript na serveru i pokreće razvojne alate.
- Express definiše API rute. GET /api/health proverava dostupnost našeg servera.
- React gradi interfejs iz komponenti. App je naša početna komponenta.
- useState čuva stanje prikazano na ekranu; useEffect ovde pokreće zahtev ka API-ju.
- JSON je format podataka koje server vraća.
- Vite pokreće razvojni frontend server i priprema produkcione fajlove.
- pnpm instalira biblioteke navedene u package.json; pnpm-lock.yaml beleži tačne verzije.
- Test proverava očekivano ponašanje automatski. Trenutno proveravamo dostupnost, nepostojeću rutu i neispravan JSON.
- Ova celina još nema bazu, korisničke naloge ni stvarne događaje.
